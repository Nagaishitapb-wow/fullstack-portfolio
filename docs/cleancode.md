1.Meaningful Names-
Code should explain itself.
Use descriptive variable, function, and class names that make intent clear.

2. Single Responsibility Principle (SRP)
Each function or class should do one thing and do it well.
Don’t mix multiple responsibilities in the same block of code.

3.Comment Why, Not What
Code should show what it does comments should explain why.

4.KISS (Keep It Simple, Stupid)
Simplicity > cleverness.

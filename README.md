# **📌 Foundation Phase (Weeks 1–2)**

---

## **Week 1 – Development Foundations & Modern JavaScript**

### **🎯 Goal:**

Establish solid software-development foundations and master modern JavaScript.

### **Topics Covered**

* Understand **Software Development Life Cycle (SDLC)** and **Agile principles**.
* Learn **clean code practices** and project organization.
* Set up the development environment:

  * **VS Code**, **Node.js**, **Git**
* Master Git workflows:
  `git init → git add → git commit → git branch → git merge → git push/pull`
* Resolve merge conflicts, manage branches, and handle pull requests & code reviews.
* Grasp **Modern JavaScript (ES6+)** concepts:

  * Variables
  * Functions
  * Destructuring
  * Spread/Rest
  * `map`, `filter`, `reduce`
* Build asynchronous expertise:

  * Promises
  * async/await
  * Error handling
  * ES modules
* **Deliverable:**
  Hands-on JavaScript project + Git collaboration simulation.

---

## **Week 2 – Web Fundamentals & API Concepts**

### **🎯 Goal:**

Master web technologies, HTTP, and API basics before moving to frameworks.

### **Topics Covered**

* Understand how the web works:
  **HTTP/HTTPS**, requests/responses, DNS, browsers.
* Build responsive UIs using:

  * **HTML5**, **CSS Flexbox/Grid**, accessibility.
* Apply design principles:

  * BEM, Tailwind, typography, color, spacing.
* Learn **HTTP methods** (GET, POST, PUT, DELETE), status codes, and REST principles.
* Practice **Postman** and explore public APIs.
* Use **Fetch API** and work with JSON data.
* Build & debug a simple API-based web app (e.g., weather app).
* Introduction to **testing mindset** and **browser DevTools**.

### **Deliverable:**

Small web application integrating a public API.

---

# **📌 Frontend Phase (Weeks 3–4)**

---

## **Week 3 – React Fundamentals & Component Architecture**

### **🎯 Goal:**

Learn React core concepts and build reusable UI components.

### **Topics Covered**

* Why React? → Virtual DOM and component-driven development.
* Set up React project (CRA or Vite).
* Write JSX syntax and foundational components.
* Pass data via **props**, structure components, and build a small UI library.
* Manage state using **useState**, handle events, forms & validation.
* Render lists with `map()`, use keys, conditional rendering.
* Use **useEffect** for side effects and API calls.

### **Deliverable:**

Full **Todo App** with API integration + code review.

---

## **Week 4 – Advanced React & Testing**

### **🎯 Goal:**

Build scalable React apps using advanced patterns & testing.

### **Topics Covered**

* Use **useReducer**, **useContext**, and create custom hooks.
* Client-side routing with **React Router** (dynamic & nested routes).
* Apply testing using **Jest** & **React Testing Library**.
* Write unit tests & simulate user interactions.
* Optimize performance with:

  * `React.memo`
  * `useMemo`
* Handle errors using **Error Boundaries**.

### **Deliverable:**

Full SPA with routing + tests + performance tuning.

---

# **📌 By the End You Will Be Able To**

* Design, build, and deploy a complete **React + Node.js application**.
* Use **Git professionally** with branching strategies and PR workflows.
* Write **clean, testable JavaScript** code.
* Apply **frontend best practices** — components, state, routing.
* Build **secure & scalable backend APIs**.
* Deploy your **portfolio project** online for showcasing.

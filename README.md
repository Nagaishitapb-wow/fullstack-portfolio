Foundation Phase (Weeks 1–2)
Week 1 – Development Foundations & Modern JavaScript

Goal: Establish solid software-development foundations and master modern JavaScript.

-Understand software-development life cycle (SDLC) and Agile principles.

-Learn clean code practices and project organization.

-Set up the dev environment — VS Code, Node.js, Git.

-Master Git workflows: init → add → commit → branch → merge → push/pull.

-Resolve merge conflicts, manage branches, and perform pull requests & code reviews.

-Grasp modern JavaScript (ES6+) — variables, functions, destructuring, spread/rest, map/filter/reduce.

-Build asynchronous understanding — Promises, async/await, error handling, and modules.

-Deliverable: Hands-on JS project + Git collaboration simulation.

Week 2 – Web Fundamentals & API Concepts

Goal: Master web technologies, HTTP, and API basics before frameworks.

-Understand how the web & HTTP/HTTPS work — requests, responses, DNS, browsers.

-Build responsive UI using HTML5, CSS Flexbox/Grid, and accessibility.

-Apply design principles — BEM, Tailwind, typography, color, spacing.

-Learn HTTP
